Mês do comissionamento

Selecione o mês de referência para importação e cálculo das comissões.

Como funciona?

Sempre o mês do pagamento/ciclo que está fechando (ex.: se é o comissionamento de Setembro, selecione Setembro aqui) — nunca o mês da planilha em si. O sistema já desconta os meses de defasagem sozinho pra achar a "Data de ativação" certa (ex.: ativação considera 2 meses antes deste campo); selecionar um mês adiantado "pra compensar" faz o desconto dobrar e erra a conta.

Enviar Link de Cadastro

Gere um link para que o parceiro preencha os próprios dados.

Como funciona?

Escolha a categoria, gere o link e envie para a pessoa preencher os próprios dados — inclusive a quem ela fica vinculada. Assim que ela salvar, o cadastro já aparece direto em "Novo Cadastro" — sem precisar de código nenhum.

Link gerado

O link já abre o formulário na categoria escolhida. Se você definir um prazo, ele aparece para o parceiro na página de cadastro.

Novo Vendedor

Cadastre um vendedor definindo suas metas trimestrais.

Como funciona?

Cria o vendedor com metas trimestrais padrão — ajuste os valores reais depois em Vendedor → aba Metas. É a esse vendedor que Indicadores, Dealers e Projetos Especiais são vinculados no campo "Comercial".

Metas trimestrais

Defina as metas padrão que poderão ser ajustadas posteriormente. Campo em branco usa o valor sugerido.
